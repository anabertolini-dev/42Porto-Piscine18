	Write a function called ft_list_remove_if that removes from the
	given list every element whose data is equal to the reference data.

	The function must be declared as follows:

	void	ft_list_remove_if(t_list **begin_list, void *data_ref,
			int (*cmp)());

	The cmp function takes two void pointers and returns 0 when the
	two values are equal.

	You must use the ft_list.h file, which contains the following
	structure:

	typedef struct s_list
	{
		struct s_list	*next;
		void			*data;
	}	t_list;
